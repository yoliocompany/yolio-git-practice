# Contributing

This repo is for learning. Your pull request is practice, not a real contribution to a product.

## Before you open a pull request

- Your branch has **one commit** (or very few).
- The commit message is in **English**, starts with a capital letter, and describes one change (for example: `Add sami to contributors`).
- You added **only** `contributors/<your-username>.md`.
- The file has **no personal data** (no email, no phone number, no home address).

## In the pull request

- Title: short and clear (for example: `Add sami to contributors`).
- Description: one sentence about what you added.

## What happens next

Maintainers may leave a comment or merge your pull request. They may also leave it open. All of these are normal.
